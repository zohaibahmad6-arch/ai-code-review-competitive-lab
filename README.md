# AI Code Review Competitive Lab

Controlled benchmark repository for evaluating AI-powered code review systems.

## Purpose

This repository contains intentionally constructed software scenarios used to evaluate:

- Bug detection
- Security analysis
- Performance analysis
- Architecture analysis
- Test coverage analysis
- Code quality
- Cross-file reasoning
- Suggested fixes
- Evidence quality
- False-positive behavior

This repository contains synthetic test code only.

## Benchmark Principles

Each test should have:

1. A known engineering issue
2. An expected finding
3. A controlled pull request
4. An independent evaluation of the AI review
5. Recorded detection and false-positive results

This repository is a product research and engineering benchmark.

## Project Separation

This repository is completely separate from all production projects.

It must never contain:

- Production source code
- API keys
- Passwords
- Access tokens
- Customer data
- Private credentials
